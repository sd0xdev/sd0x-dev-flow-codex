# Review and verification dispatch

Read the active installed `skills/review/SKILL.md` and its selected mode before dispatch. A default worktree review uses provider, snapshot, round begin, the configured read-only primary, round import and gate pass in that order. A full-history configured subagent inherits the parent model and reasoning effort; do not pin or substitute them. Investigation helpers and parent prose cannot satisfy the gate. Do not supply a conclusion for the reviewer to repeat.

A pending, interrupted, failed or unparseable dispatch remains pending/failed. Diagnose transcript, session activation, registry, profile and round identity through the installed doctor and local runner. Recover within existing technical-recovery authorization. Never use fallback authority, hand-edit protected state, or interpret a process exit as a clean review. Every retry begins a fresh authenticated round; preserve old evidence and fail-closed handling of late findings.

Only after the exact current fingerprint passes configured review, read the installed verify skill and run its deterministic verifier. An edit, including a fix to a reported finding, reopens every required gate. Advisory review modes and request acceptance are separate from worktree gates. Gate completion does not itself establish task completion.
